# vlog 剪辑流程（初稿，待 review）

skill 的骨架。确定后再写成 `skills/vlog-edit/SKILL.md`。

## 输入和输出

| | |
|---|---|
| 素材 | 一次旅行的文件夹：无人机（DJI，无声）+ 运动相机（VID_*.mp4，有原声；同名 LRV 是低清预览） |
| 旁白 | 你自己录。我写稿，你照稿录 |
| 音乐 | 只用免费来源（见 `music-sources.md`）：你从免费曲库下载给我，或者我用 ACE-Step 在本地按段落生成；我检测节拍和段落 |
| 成片 | 横屏 16:9，6–15 分钟，4K 或 1080p |

每次旅行在 `projects/<旅行名>/` 下建一个项目文件夹，放素材清单、转写稿、大纲、剪辑表、预览片。素材本身不复制，原地引用。这样换个会话也能接着做。

## 七个阶段

### 1. 素材盘点（全自动）

- 读出每段素材的时长、分辨率、拍摄时间、有没有声音，按拍摄时间排成整趟旅行的时间线
- 每段素材抽帧做缩略图（优先用 LRV 低清预览，快很多），我逐段看画面
- 有声音的素材全部转写成文字稿，地名先放进识别提示，过滤掉纯音乐段的乱码
- **产出 `index.md`**：每段素材一行，写拍摄时间、地点、画面内容、说了什么、可能的用处（钩子、笑点、知识点、美景、人物）

### 2. 找故事（我先找，再问你）

- 从素材清单里挑出：最好的画面、最真实的现场反应、出状况和反转的时刻、能讲知识的地方、人的故事
- 查证要讲的知识点（地理、历史、数字），旁白里不写没查实的事
- **问你几个问题**：这趟旅行对你意味着什么？最难忘的一刻是什么？有什么素材里看不出来的背景？这些我从画面里猜不出来

### 3. 大纲（你 review，可以来回几轮）

按 `storytelling.md` 的结构写：冷开场 → 片名 → 设定处境 → 每段小故事 → 情绪高点 → 收尾。每一段写清楚：

- 这段讲什么，作用是钩子、知识、笑点还是情绪
- 用哪几段素材的哪几秒
- 旁白稿，逐句写出
- 音乐怎么走：哪里快、哪里留呼吸段
- 预计时长

**你确认大纲之前，我不动手剪。**

### 4. 旁白

- **成片不用 AI 配音**，旁白都是你的声音。大纲和旁白稿确认后你就录，我直接按你的录音剪，不做临时配音
- **你录音**：照稿子录，可以一个文件录完。说错不用停，停一两秒把那句从头再说一遍。每句前后留点空白。手机录即可，嘴离手机约 20 厘米，选有窗帘、衣物的小房间
- **我剪音频、对时间轴**：
  1. 逐字转写，带每个字的时间戳
  2. 和稿子逐句对齐；同一句录了几遍，默认用最后一遍，你可以指定
  3. 切掉 NG、长停顿、"嗯啊"、咂嘴；降噪；统一音量；句间留自然呼吸
  4. 字幕文字用稿子原文（不用识别结果，避免错字），时间用逐字时间戳；长句按停顿拆成 2–3 行，跟着说话节奏出现
  5. 画面跟着旁白剪：说到什么，就切到什么
  6. 成片再转写一遍，核对字幕和声音一字不差
- 改稿只需补录改动的句子，我替换进去，其他不动

### 5. 粗剪预览（720p，几分钟出片）

- 按大纲排时间线：说话段用原声，旁白段配画面，空镜段卡音乐拍点
- 加字幕（`storytelling.md` 里的规格）、片名、位置时间标签、照片插入、"下一站"卡
- 混音：有人说话时音乐自动压低，整体响度 -14 LUFS
- **自查后再给你看**：剪辑点是否在拍点上、字幕是否和声音一致、有没有黑帧或跳帧、响度是否达标

### 6. 修改（你提意见，我改，循环）

"这段太长""这里换个镜头""旁白改一句"之类，改完重出预览。

### 7. 成片

- 按 4K 或 1080p 导出
- **可选**：导出剪映草稿或 Final Cut 工程，你在剪映里继续精修调色、加特效

## 整片剪辑时的实际做法（2026-10 薄荷岛整片验证过）

1. 素材盘点（`ingest.py`、`transcribe.py`）→ 稳定度分析（`stability.py`）→ 看总览板和长镜头缩略图，找精华
2. 用户给一段行程简介 → 我按章节扩写旁白稿，查证知识点；从全部转写里挑能用的口播（`clean_speech.py`）
3. 在项目的 `build_full.py` 里用 `edl_builder.py` 写整片：冷开场 ≤ 20 秒 → 出发 → 各章节（海报式章节卡 + 一首歌）→ 结尾
4. 渲染前自查：每首歌够不够长、有没有镜头被素材长度截短、旁白有没有压到口播上
5. 整片渲染（多镜头并行，约 1 秒渲染 1 秒成片），自检通过后逐章抽帧检查，再交付
6. 旁白以字幕形式出现、音乐自动压低；用户照字幕录音后替换进去
7. 用户提修改 → 改 `build_full.py` 里对应的几行 → 只重渲改动的那一章（或整片，约 10 分钟）

### 第二版时补上的规则（2026-10-15）

- 盘点后先跑 `dedupe.py` 找重复素材；照片单独建 `photos.json`，和视频一起按时间排
- 剪辑表由 `edl_builder.py` 检查：同一段画面不用两次、预告用过的不进正片、正片不倒退时间、口播前后留白
- 先按场景写"音乐表"：每段三个情绪词、哪首歌、从哪里进、在哪里淡出；**哪些地方完全停掉音乐、为什么**（唱歌、现场演奏、瀑布、教堂、呼吸声）。这张表和大纲一起给用户看
- 交付前逐页看整片缩略图（每页 30 个镜头），检查片名、章节卡、照片、转场和每个停音乐的地方
