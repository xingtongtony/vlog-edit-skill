# vlog 剪辑流程（和片主约定的）

谁做什么、什么时候给片主看。命令和剪辑规则不写在这里：命令见 `skills/vlog-edit/SKILL.md`，怎么讲故事、怎么剪见 `storytelling.md`。

## 输入和输出

| | |
|---|---|
| 素材 | 一次旅行的文件夹：无人机（DJI，无声）、运动相机（有原声）、手机视频和照片 |
| 旁白 | 片主自己录。我写稿，片主照稿录；成片不用 AI 配音 |
| 音乐 | 只用免费、可商用、能发各平台的（`music-sources.md`），不用付费曲库；每一期都换新歌 |
| 成片 | 横屏 16:9，6–15 分钟，1080p |

每次旅行在 `projects/<旅行名>/` 下建一个项目文件夹，放素材清单、转写稿、剪辑脚本、剪辑表、预览片。素材本身不复制，原地引用；外接硬盘不稳时，只把这一版用到的素材拷到本机。换个会话也能接着做。

## 七个阶段

### 1. 素材盘点（全自动）

- 读出每段素材的时长、拍摄时间、地点，按当地时间排成整趟旅行的时间线（相机时钟不对的先校正）
- 每段素材抽帧做缩略图，我逐张看；有声音的素材全部转写成带逐字时间戳的文字稿，地名放进识别提示
- 测每段素材的晃动、翻滚、航拍方向，找出重复素材

### 2. 找故事（我先找，再问片主）

- 从素材里挑出：最好的画面、最真实的现场反应、出状况和反转的时刻、能讲知识的地方、人的故事。转写稿里每段有内容的口播都要过一遍
- 查证要讲的知识点（地理、历史、数字），旁白里不写没查实的事
- **问片主几个问题**：这趟旅行对你意味着什么？最难忘的一刻是什么？有什么素材里看不出来的背景？

### 3. 大纲（片主 review，可以来回几轮）

按 `storytelling.md` 的结构写：开场 → 片名 → 设定处境 → 每段小故事 → 情绪高点 → 收尾。每一段写清楚：

- 这段讲什么，作用是知识、笑点还是情绪；和上一段怎么接
- 用哪几段素材的哪几秒
- 旁白稿（按段写）；不配音的地方写"【不配音】+ 原因"，航拍写"【航拍】+ 哪一种"（第一眼 / 形状 / 收尾 / 片名），用户素材里没有、要从图库补的标出来
- 音乐表：每段三个情绪词、哪首歌、从哪里进、在哪里淡出；**哪些地方完全停掉音乐、为什么**

**片主确认大纲之前，我不动手剪。**

### 4. 旁白

- 整片旁白稿写完，先过一遍编辑审稿，再给片主
- 替片主写的心情和判断都标出来，片主按真实感受改了再录
- **片主录音**：一段一个录音，看着稿子一口气读完，不跟着画面上的字幕读。说错了停一两秒，从这一句开头重来。手机录即可，嘴离手机约 20 厘米，选有窗帘、衣物的小房间
- **我对时间轴**：逐字转写录音，和稿子逐句对齐（同一句录了几遍默认用最后一遍）；切掉 NG、长停顿、"嗯啊"；字幕用稿子原文，时间用逐字时间戳。成片再转写一遍，核对字幕和声音一致
- 改稿只需补录改动的那几段

### 5. 预览（1080p）

- 按大纲排时间线，加字幕、片名、时间地点戳、照片、新闻剪报，配乐和混音
- **自查后再给片主看**：渲染自带的自检（帧数、剪辑点、口播同步、人声高过音乐、静音段、响度）全部通过，再逐页看缩略图（每页 30 个镜头），检查黑镜头、文字位置、照片、每个停音乐的地方，逐段核对口播没有被截断
- 交付时附上旁白稿

### 6. 修改（片主提意见，我改，循环）

"这段太长""这里换个镜头""旁白改一句"之类：改剪辑脚本，先只渲染改动的那一段给片主看，同时在后台渲整片。片主的反馈和从中总结的规则，写进 `storytelling.md` / `toolchain.md` 对应的那一节（新规则替换旧规则，不并存）。

### 7. 成片和发布

- 1080p 导出（码率上限 16 Mbps）
- 小红书封面和文案见 `publishing.md`

## 和剪映配合

整片渲染一次要 20 多分钟，每改一处都等一轮太慢。分工：

| 改动 | 谁来做 | 怎么做 |
|---|---|---|
| 字幕大小、改字、音乐音量、挪剪辑点、删换个别镜头 | 片主在剪映里改 | 打开"<片名>（Claude 导出）"草稿，改完直接导出 |
| 重新选镜头、换歌、改结构、重写旁白 | Claude | 改剪辑脚本，先渲染改动的那一段给片主看（`--shots`，几分钟），确认后重新导出剪映草稿 |
| 关键画面（片主点名的镜头、要配旁白的生物） | 先截一帧给片主确认 | 再进剪辑 |

导出草稿：`python3 scripts/export_jianying.py <剪辑表> "<草稿名>" --replace`，导出前片主先按 ⌘Q 退出剪映。草稿打开后和成片一致（调色、字幕、标题、音乐、照片、漏光都在）。片主在剪映里改过的，用 `compare_cut.py` 读回来，做进剪辑脚本后再重新导出。
