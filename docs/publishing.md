# 发布到小红书：封面和文案

成片定稿后、发帖前做两件事：封面，和标题 / 正文 / 话题。

## 规格（第三方资料一致的说法，发布页的实际选项为准）

| 项目 | 规格 |
|---|---|
| 封面比例 | 只有 3:4、4:3、1:1 三种；竖版 3:4 在信息流里占的面积最大，多数作者用它。横屏视频也可以单独上传一张 3:4 封面 |
| 封面尺寸 | 1080 × 1440 |
| 标题 | 最多 20 字，标点、空格都算 |
| 正文 | 最多 1000 字 |
| 话题 | 最多 10 个；在 App 里输入 # 选联想出来的已有话题 |
| 排序 | 评论 > 收藏 > 点赞（较早的资料）；笔记里的关键词影响搜索，所以标题、正文里要有地名和活动名，结尾留一个问题引导评论 |

信息流里一张封面在手机上只有拇指宽：发之前把封面缩到 180 × 240 看一眼，标题字要还认得出。

## 封面：先学这个账号自己的样式

**不要套通用模板。** 第一版用了黄色色带加大字口号（“水性不好的我 / 5 天考下两张潜水证”），片主说太不像自己的账号：这个账号偏文艺。先要片主之前的封面截图（不登录看不了小红书搜索页，个人主页也可能要登录），拆出这个账号的视觉语言，新封面跟着它走，让系列放在一起像一套。

这个账号（Tony Vlog / 搓泥…环游记）的样式，供对照：

- 3:4 卡片由三条通栏横图上下拼成（有时两条），不留缝
- 标题放在中间那条：手写体地名，竖排、横排，或者左右分开（“喀什 / 噶爾”）；“Tony Vlog”用手写英文或圆头粗体大写压在地名上；有时加系列名“搓泥新疆环游记”
- 一张只用一个强调色，从画面里取（草地上的字用深绿）；白、黄、橙、浅蓝
- 上下两条配一行宋体小字说明，字距拉得很开（“甘肃的第一个海关”）
- 人在其中一条里，多是背影或侧影
- 系列名有时放在底部正中，白色粗体小字

## 封面：高级感从哪来

片主给了十几张自己觉得“高级”的封面（小红书搜“vlog”的热门结果），第三版封面照着重做。共同点：

| 原则 | 怎么做 | 反例（被否掉的版本） |
|---|---|---|
| **一个主角，其余极小** | 一个巨大的词（英文地名或“Vlog”）铺满一条或半个画面；其余文字是细的小标签、字距拉开的大写、一行小手写 | 好几组字差不多大，互相抢 |
| **主体压在字前面** | 人或动物挡住大字的几个字母，立刻有纵深（PHUKET、Vietnam、Sydney 都这样）。用 `scripts/subject_mask.swift` 抠主体 | 字平贴在画面上 |
| **克制** | 字少；严格的边距（64 px）和对齐；留白 | 塞满口号、标签、说明 |
| **颜色从画面里取** | 一个强调色：黄、深海蓝、珊瑚红，或者白 | 每行字一个颜色 |
| **不加黑色阴影** | 字放在画面里干净的地方（天空、海面、纯色水），浅底用深色字 | 每行字都加阴影，显得廉价 |
| **重 + 轻的搭配** | 一款很重的展示字（Anton、Fredoka）配一款很轻的小字（Instrument Sans / Serif、细手写） | 全用中等粗细 |

Anthropic 官方的 canvas-design skill（github.com/anthropics/skills）讲的是同一套：一个巨大的词配极小的标签，字要少、多用细字，元素之间留白不意外重叠，配色少而统一；打磨时不往上加东西，而是把已有的做精。小红书上的另一个封面 skill（ponyo-cover-anchor-system）偏“信息密度”的大字报，借用一个概念就够了：画面里要有一个让眼睛停住的锚点，缩略图里一眼看清。

## 封面：怎么做

用 `scripts/cover_kit.py`，每一期只写一个很短的 `projects/<trip>/publish/make_covers.py`（薄荷岛那份是示例，三张封面各一次调用）：

```python
from cover_kit import Kit, full_bleed_hero, triptych_hero, triptych_signature, YELLOW, SUN, NAVY
k = Kit(project_dir)
triptych_hero(k, 'cover_B.jpg', [('c114', 28.0, .5, .5), ('c154', 122.0, .46, .42), ('c143', 9.5, .5, .5)],
              'BOHOL', YELLOW, tag='TONY VLOG', series='搓泥菲律宾环游记')
```

| 版式 | 函数 | 样子 |
|---|---|---|
| 整张大字压主体 | `full_bleed_hero` | 一张图，巨大的地名在主体后面（海龟游在 BOHOL 前面），四角小标签，左下一行标题 + 一行小字 |
| 三联大字压主体 | `triptych_hero` | 三条横图，中间那条的地名横跨整条、压在人后面（PHUKET 那种）。**薄荷岛选的是这个** |
| 三联签名式 | `triptych_signature` | 三条横图，一条的干净处放圆头“Vlog”，地名用窄衬线斜体签在它的底线上（Vlog New Zealand 那种） |

步骤：

1. **画面从原始素材取，不从成片截**：成片压着字幕、只有 1080p。`Kit.frame` 用 `scripts/grade.py` 的 `clip_filter` 套和成片一样的调色截图（4K 运动相机、无人机裁成竖版也清楚），缓存在 `publish/frames/`（不进 git）
2. **确认画面在片主的最终版里**：片主可能在剪映里改过。把候选帧和最终导出的视频做指纹比对（`scripts/compare_cut.py` 用的 48×20 灰度相关，> 0.95 即找到），封面画面要在视频里真的出现
3. **按主体位置裁**：每条横图给 `(clip, t, cx, cy)`，`cx / cy` 是主体在原画面里的位置
4. **主体压字**：`Kit.subject` 调 `swift scripts/subject_mask.swift <帧> <蒙版> subject|person`（macOS 自带的 Vision，不用下载模型）。先画大字，再把同一张图按蒙版贴回去，主体就在字前面。`subject` 抠所有显著主体，海龟、整个潜水员都很干净；`person` 只抠人，水下只抠得出头部；有时 `subject` 抠中的是背景里的另一个人（c143），这种画面就不做压字
5. **字体**：只用年轻、时尚的字体，从 `fonts/README.md` 选。第二版用了龙藏体（毛笔手写），片主说“看着很老气，不时尚也不年轻”；后来又指出思源黑体、思源宋体、Montserrat、Playfair 这类古典或太“标准”的字体也显老，都已移出字体库。例外：思源宋体 Black 后来加回来了，只配合做旧纹理用在视频片名上（片主自己剪的薄荷岛片名就是做旧粗宋），封面不用。很多中文手写字体只有简体：`check_glyphs` 遇到缺字直接报错（第一版“薄荷島”的“島”画成了空方框，自检没拦住）
6. **每次出图都缩到信息流大小（180 × 240）看一眼**，一次给 3 个方向让片主挑

## 文案

正文结构（薄荷岛那篇 463 字）：

1. **开头几行短句**：片子的主线（“这座岛上的山，几百万年前还在海底”），不要流水账，语气和账号一致
2. **一句话的结果**：十一天，两张潜水证；从三米泳池到三十米崖壁
3. **这一期有什么**：5–6 个画面级的亮点，每行一个 emoji
4. **一点实用信息**：从旁白和口播里整理交通、时长、住哪、季节、价格坑、健康提醒。这是别人收藏和搜索的理由。不知道的（潜店名、价格）不要编，留空让片主填
5. **一个真诚的问题**引导评论

标题给 2–3 个（数字数），各有侧重：和封面主线一致的文艺版、带搜索词的版本、故事加结果的版本。话题 10 个：地名大词（#薄荷岛 #菲律宾旅行）、活动词（#潜水考证 #AOW）、类型词（#旅行vlog #海岛旅行）、景点词（#巧克力山）、片主的系列名。

## 版权

配乐只用免费且允许跨平台发布的（`docs/music-sources.md`）。片主想用的商业歌曲不从 YouTube 扒：能做的是找风格相近的免费曲，或者片主自己买正版下载、自行承担发布风险，或者在平台曲库里加。
