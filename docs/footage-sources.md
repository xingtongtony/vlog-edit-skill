# 免费视频素材（转场叠加、空镜）

只收免费、可商用、可发 B 站 / 小红书 / YouTube 的。调研时间 2026-10-15；"核实"写信息来源（官方 / 二手）。用之前再看一眼该素材页面上的授权。

## 先用代码生成，不够再找素材

很多转场不需要外部素材，`render_preview.py` 直接生成，没有授权问题，风格也能统一：

| 效果 | 怎么做 | EDL 写法 |
|---|---|---|
| 漏光闪光 | 代码生成暖色边缘光，盖在剪辑点上 | `"fx": [{"type": "leak", "cut": 17, "dur": 0.9}]` |
| 从黑暗中亮起 | 镜头开头淡入 | 镜头里加 `"fade_from_black": 1.0` |
| 打字机时间戳 | 逐字出现 + 光标 | `"typewriter": [{"shot": 18, "text": "05:31 AM", "sub": "宿务 · 菲律宾", "y": 0.10}]` |

还没做、但可以用代码做的：胶片颗粒和划痕、甩镜动态模糊、画幅变化（竖幅 / 4:3 黑边）、大字铺满画面。

需要外部素材的情况：**真实拍摄的胶片烧边、光斑**（比代码生成的更有质感），以及**用户素材里没有的空镜**（城市延时、航拍、天空）。

## 来源

| 来源 | 适合找 | 授权 | 核实 |
|---|---|---|---|
| **Pexels**（pexels.com/videos） | 空镜：城市、自然、天空、海 | 免费商用，不用署名；可以用在自己剪的 YouTube 视频里，不能原样转传或转卖；画面里有可识别的人时不保证有肖像授权 | 官方帮助中心 |
| **Mixkit**（mixkit.co/free-stock-video） | 空镜、少量转场 | 分两档：**Video Free License 可商用**（YouTube、社交平台）；**Restricted License 只能非商业用**，每个素材页面要看清是哪档；不用署名 | 官方页面 |
| **Coverr**（coverr.co） | 空镜，生活方式类 | 免费商用，不用署名，可以剪裁和二次创作；不能原样转传 | 官方授权页（API 文档写"需署名"，和授权页冲突，以授权页为准） |
| **Pixabay 视频** | 漏光、胶片烧边叠加素材很多（搜 "light leaks film burn overlay"） | 免费商用，不用署名 | 二手；**网站有 Cloudflare 真人验证，自动化访问会被拦，需要用户自己下载** |
| **FX Elements** | 专业的特效叠加（光效、烟雾、火花） | 免费素材可商用；要注册账号 | 二手 |
| **Enchanted Media 漏光包**（Gumroad 免费） | 20 个漏光转场 | 发布方写着可商用、可用于盈利的 YouTube 视频 | 二手 |
| **Vecteezy** | 漏光叠加 | 很多是付费会员专享，要筛选免费并看每个授权 | 二手 |

## 用的时候

- 叠加类素材（漏光、烧边）选**黑底**的，叠加时用滤色 / 加亮方式，黑色部分自动消失
- 空镜要和用户素材**风格接近**：色调、分辨率、拍摄高度、天气；用之前先过一遍全片调色
- 每用一个素材，和音乐一样在项目里记授权：`footage/LICENSES.md`（文件、来源链接、授权档位、下载日期、截图）
