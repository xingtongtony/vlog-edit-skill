# 免费视频素材（转场叠加、空镜）

只收免费、可商用、可发 B 站 / 小红书 / YouTube 的。调研时间 2026-10-15；"核实"写信息来源（官方 / 二手）。用之前再看一眼该素材页面上的授权。

## 先用代码生成，不够再找素材

很多转场不需要外部素材，`render_preview.py` 直接生成，没有授权问题，风格也能统一：

| 效果 | 怎么做 | EDL 写法 |
|---|---|---|
| 漏光闪光 | 代码生成暖色边缘光，盖在剪辑点上 | `"fx": [{"type": "leak", "cut": 17, "dur": 0.9}]` |
| 从黑暗中亮起 | 镜头开头淡入 | 镜头里加 `"fade_from_black": 1.0` |
| 时间地点戳 | 左下角细字，地点先出、时间晚一拍（规则见 `storytelling.md` → 画面文字） | `b.place('罗威纳', '06:10')` |

还没做、但可以用代码做的：划痕、甩镜动态模糊、画幅变化（竖幅 / 4:3 黑边）、大字铺满画面（胶片颗粒已经在调色的 `film` 档里）。

需要外部素材的情况：**真实拍摄的胶片烧边、光斑**（比代码生成的更有质感），以及**用户素材里没有的空镜**（城市延时、航拍、天空）。

## 用的时候

- 叠加类素材（漏光、烧边）选**黑底**的，叠加时用滤色 / 加亮方式，黑色部分自动消失
- 空镜要和用户素材**风格接近**：色调、分辨率、拍摄高度、天气；用之前先过一遍全片调色
- 每用一个素材，和音乐一样在项目里记授权：`footage/LICENSES.md`（文件、来源链接、授权档位、下载日期、截图）

## 用户素材里没有的航拍（2026-10-25，巴厘岛精灵坠崖试过）

航拍只给大场景（`storytelling.md` → 航拍）。用户没带无人机、又需要"第一眼"或"形状"镜头时，从图库补：

**去哪找**
- **Pexels**：热门景点基本都有 4K 航拍。网页对脚本返回 403，API 要用户自己注册的 key，所以在内置浏览器里搜（`pexels.com/search/videos/<地名>/`）。视频页上有分辨率、帧率和一个 Date，那是**上传日期，不是拍摄日期**，只能参考。原片地址在页面 `__NEXT_DATA__` 的 `video_files` 里（`videos.pexels.com/video-files/...`），用 curl 加代理下载。大文件会被截断却不报错：用 `-C -` 续传，下完用 `ffmpeg -v error -i <文件> -f null -` 完整解码一遍
- **Wikimedia Commons**：API 不用 key，带拍摄日期和逐条授权，但数量很少（"Nusa Penida drone" 0 条）
- **YouTube**：大多是标准许可，不能用，不管用什么网站下载。标了"知识共享 CC BY"的可以用，要署名；用第三方网站下载违反 YouTube 的使用条款（账号层面的事，由片主决定）。很多视频写明了具体地点和拍摄时间，比图库好对季节
- 不用 NC（不许商用）、ND（不许改动，调色剪辑都算）、SA（改过的画面要用同样授权分享，可能牵连整片）

**挑哪条**
1. **地点**：标题或描述里写明具体地点（"Kelingking Beach"），再看画面里的地标核对。"tropical beach drone" 这种泛泛的不用
2. **季节和天气**（调色调不回来的先对上）：把候选的预览图和用户同一个地方、同一天拍的画面拼成一张板对照：植被绿还是黄、稻田在哪个阶段、阴天柔光还是晴天硬影子和蓝天、浪、一天里的什么时间。巴厘岛 2 月是雨季：精灵坠崖有 3 条崖壁枯黄（旱季），直接排除；8960401 是大晴天，调完色接在阴天的镜头旁边仍然看得出来
3. **运动**：和用户的航拍一样，只用一个方向的那一段（看 1 fps 缩略图）

**调色和加进项目**：`python3 scripts/add_stock.py <项目> <原片> <起> <止> --ref c360:3 c367:9 ... --url <页面> --author <作者> --license "Pexels License"`
- 用 `--ref` 给的用户画面（选同一天、构图接近的：天、海、植被的比例差不多）在 Lab 色彩空间里算一张调色表（`.cube`）：亮度和对比往用户的画面拉，颜色只挪均值、浓淡最多改 15%，整体只做 60%。整张画面硬拉的版本会把深海拉成浅绿松石色、把植被拉得太艳
- 输出 1080p、29.97 帧的调色版到 `<项目>/stock/matched/`，作为 `s01`、`s02`……追加进 `clips.json`（不重排已有的编号），做好代理文件，授权写进 `<项目>/stock/LICENSES.md`。之后跑 `motion.py <项目> s01`，就能像用户自己的航拍一样进剪辑脚本，全片的电影感色调照常套在上面
- 重新跑 `ingest.py` 会重建 `clips.json`、丢掉这些 `s` 编号，要重新加一遍
- 旁白不说"我们飞了一圈"，不把别人拍的说成用户拍的
