# 旅行 vlog 叙事与剪辑方法

剪片、写旁白之前先读这份。这些规律来自几支高质量旅行 vlog 的拆解（样本见文末），是通用做法，不属于某一个人。

## 最重要的一条：不要写流水账

"第一天去了 A，第二天去了 B"是最难让人看下去的写法。观众不关心你按什么顺序去了哪里，只关心**接下来会发生什么、为什么值得看**。

时间顺序可以保留，作为片子的骨架，但旁白不能拿来报行程。每一段旁白都要做下面至少一件事：

| 旁白要做的事 | 例句 |
|---|---|
| 抛出问题或悬念 | "但在行程开始前，另一件事儿把我们难倒了" |
| 制造期待，再给反转 | "所有火山都建议凌晨攀登……雨季除外" → "运气依然没有站在我们这边，但却也感受了一次不一样的云雾中的 Bromo" |
| 给出画面里看不出的知识 | "数百年来他们每年都会向火山口下投下祭品，祈求山神的庇佑" |
| 讲人的故事 | "我们的父辈在这里用健康换取生命" |
| 把情绪推到高点 | "那一刻像闯入了地球的另一个维度" |

**反例**（薄荷岛 v1 的旁白，典型流水账）：

> 十月初，我们来到了菲律宾的薄荷岛。/ 一千多座圆锥形的小山，散落在森林里。/ 下午，我们去了海边的一座老教堂。/ 第二天，住进了一家海边的酒店。

每句都在报"什么时候、去了哪"，没有悬念、没有知识、没有情绪。改写方向：

> 从天上看，这些山像有人随手撒下的一把巧克力。/ 一千多座，几乎一模一样。/ 当地传说，是两个巨人打架时扔下的石头……

## 场景之间怎么接（巴厘岛 v2 之后，2026-10-24，片主："每到一个新地方就直接硬切过去，没有缓冲……像流水账"；调研见下）

衔接不一定要路上的素材。一句旁白、一个声音、一处前后呼应，都可以把两段接起来。关键是观众被带过去，而不是被扔过去。

- **每次换地方都是一个过桥段**：
  1. **离场**：上一段落在一个安静的收尾上，比如一个反应、一个远景、一句话说完后留 1–2 秒，声音拖尾 1–2 秒（`lcut`）
  2. **过桥**：一句旁白，或者用户自己的一句话，把观众带过去。句型可以是：
     - 空间："离开海边往山里开……"
     - 时间："第二天一早……"
     - 因果："晚饭没着落……"
     - 对比："前一晚的人还在 Finns 跳舞，第二天早上六点一刻……"
     - 往前埋钩子："出发前我们还不知道，这会是这一路住得最离谱的地方"
  3. **抵达**：新地方先用一个远景或大景（≥3 秒），声音提前 0.5–1.5 秒进来（`jcut`），1–2 秒自然声之后才有人开口（`vo(..., lead=1.0–1.2)`）。时间地点戳在远景出现后再上。大场景的第一眼空得更久：4–8 秒（见"不配音的镜头"）
- **跨度分级**：
  - 同一场景内：硬切，加 J/L 声音
  - 同区域换场：4–8 秒的过桥段
  - 换岛、换城、换天：10–16 秒的过桥段，只有这一级用叠化
- **把"然后"换成"但是 / 所以"**：每两个地点之间如果只能用"然后"连，就补一个因果或一个对比。例如：
  - 看完海豚 → 下午"自己出海钓点什么"
  - 钓鱼没收获 → "那天的晚饭，没有鬼头刀"
  - 脏酒店 → "我们只想要一个干净的房间" → 苍古"这间房子里早就有住客了"（那窝鸟）
- **埋伏笔、再回收，把散的段落缝起来**：
  - 乌布：从国内带的过滤花洒 → 佩尼达：三秒钟滤芯变色
  - 苍古：外号"体校" → 06:15 的晨跑
  - 开头"那个巴厘岛还在吗" → 结尾回答
- **用户自己的话最好当桥**：比如"我们现在准备过去看一看"、"房东还给了几张健身券"，比旁白更自然
- **同一个地方去了两次，合成一段**（巴厘岛 v2，片主："你能不能把那个精灵坠崖两段儿剪成一段"）：按时间拆成两段，中间隔着别的内容，观众会觉得重复。合成一段时，第一次的镜头在前，第二次的在后，用一句旁白交代清楚（"精灵坠崖，我们来了两次。第一次是前一天傍晚……第二次，我们干脆爬到了底下的沙滩"），时间顺序检查用 `back=True` 放行

## 整体结构

| 段落 | 时长 | 做什么 |
|---|---|---|
| **开场** | 约 30 秒 | 照片主自己的泗水那期：一个安静的建立镜头，接一段预告旁白按路线点名（"这一次……先去……最后……"），每一站配**这一站最好的一个镜头**（有人或有动作，2–4 秒，不放空海面），一个场所只出现一次，最后一句定调。素材里真有特别好笑或惊人的一句原声，才放在最前面；没有就不硬做钩子（巴厘岛 v1 被片主否了） |
| **片名** | 约 0:30 | 落在航拍大景上，样式见"画面文字" |
| **设定处境** | 片名后 1–2 分钟 | 对镜头交代：这地方为什么难去、我担心什么、这次想看到什么。给全片一个要回答的问题 |
| **主体** | 多数时长 | 按路线推进，但每一段都是一个完整小故事（见下） |
| **情绪高点** | 倒数 2–3 分钟 | 留给最有分量的内容：人的故事、最壮观的景象。旁白放慢，镜头放长 |
| **收尾** | 最后 30–60 秒 | 照片主自己剪的薄荷岛：最后一段旁白回答开头的问题，压在人物镜头上（他们自己、同伴，放松的长镜头），留 3 秒只有自然声，再接一个大景，开场的片名逐字再现一次；开场那首歌回来，对齐到它自己的结尾唱完（`b.end_on_last_bar()`）。不用 "See you" 卡、"下一站"卡 |

**不默认分章节**：章节卡显得死板（巴厘岛 v1 被片主否了）。分段靠时间地点戳、换歌、航拍大景、日夜交替。

## 每一段小故事怎么搭

1. **进入**：一个建立空间的大全景或航拍，再上时间地点戳（"罗威纳 | 06:10"，样式见"画面文字"）
2. **体验**：现场原声，包括和同伴、向导、当地人的对话，吃东西，爬山喘气，出状况
3. **知识**：旁白配画面讲背景。顺序是：在哪 → 有什么特别（"被誉为地球上最像月球的地方"）→ 一个感官画面 → 当地人的文化或历史 → 一句诗意收尾（"站在这里你能听见大地最原始的呼吸"）
4. **落点**：美景段落，只留画面和音乐，作为这一段的句号

不是每段都要四步齐全，但**知识和落点不能都缺**，否则就退化成流水账。

## 三层信息

好的旅行片同时有三层，要交替出现：

- **体验层**（现场原声）：轻松、好笑、真实。换汇时数零、厕所收费、吃到发霉的零食，这些小插曲是节奏的调味剂，也是人物性格
- **知识层**（旁白 + 地图、资料画面）：数字、历史、地理，让观众觉得"学到了"
- **人的层**（旁白或对话）：当地人的生活、工作、代价。最容易打动人，适合放在高潮

## 节奏

- **镜头长度**：中位数约 4 秒；快段落 2 秒左右，对话长镜头可以到 60 秒
- **每分钟剪辑数随内容变化**：开场和赶路段每分钟 15 刀左右；夜间攀登、情绪段每分钟只有 2–3 刀；人物故事段回到每分钟 10 刀左右
- **快慢交替**：白天信息密、笑点多；黎明、黄昏、夜晚放慢
- **镜头时长按分量给**：撑起一段的镜头（海豚跃出、悬崖、店门口那一眼）多给 2–3 倍，过场空镜 1.5–2 秒；不要平均分（巴厘岛 v1，片主："每个片段时长好像都特别平均"）。`vo()` 的 B-roll 用权重 `w`；连续 4 个时长差不到 0.4 秒的空镜会被提醒
- 6–15 分钟的片子，宁可删掉一段不重要的，也不要把每段都压短

## 不配音的镜头：让观众自己感受（2026-10-25）

片主："有一些氛围感的镜头……给用户一段镜头，让他感受这个氛围的时候，就不需要配音了。"

**判断标准**：把这句旁白删掉，观众少知道了什么？如果只少了"美""壮观""震撼"这类画面本身已经在说的话，就删掉旁白，只留画面和声音。旁白只讲画面讲不出来的：背景、原因、看不见的事实、心里的感受。

**五种时刻不配音**：

1. **第一眼**：每个大地方的第一个镜头先空 4–8 秒，像拉开幕布，旁白在后面再进（`vo(..., lead=5, quiet='第一眼看霸王龙崖')`）。巴厘岛 v4 一到精灵坠崖崖顶旁白就开始讲
2. **高光本身**：海豚成群出水、日落、跑团出发。观众该"哇"一声的时候没有旁白；现场的尖叫和原声照留。巴厘岛 v4 海豚那段旁白一直压着
3. **声音就是内容**：海浪、雨夜的摩的、寺庙、现场音乐（和"什么时候必须把背景音乐全部停掉"那张表是同一批场景）
4. **一句重话之后**：情绪话、笑点之后留 1–3 秒
5. **时间在过去**：日落变成夜、船开出港这种过桥段

**呼吸段**：每 3–5 分钟，尤其在一个大场面或一句重话之后，留 20–30 秒不说话、只有画面和音乐（或只有环境声）的段落（到达新地方、日落、夜景）

**怎么落到流程里**：大纲里每个不配音的地方写"【不配音】+ 原因"，片主看大纲时就能改；剪辑脚本里用 `b.quiet(原因, 秒数)` 标在下一个镜头上，或者 `vo(..., quiet=原因)` 标在旁白前面空出来的那几秒上。标了不配音的地方被旁白压上就报错；超过 5 分钟没有一段 20 秒以上没人说话的地方，保存时提醒。导出的旁白稿里会写出每个不配音的地方，片主录音时知道哪里不用说。巴厘岛 v4 最长一段没人说话的只有 13 秒。

## 全片要有一条主线

把一趟行程串起来的，不是时间，而是一个贯穿全片的问题或愿望。

- **开头抛出来**：设定处境那一段，用一个问题或一个想要的东西收尾。例如追着一位古人的足迹，开头问“几百年后，这里还是他眼中的样子吗”；或者“想看一次云海”
- **中途受挫**：想要的东西一次次落空（天气、错过、爆胎），每次落空都推着故事往前走，也逼人物想明白一点什么
- **结尾回答**：最后一段旁白回答开头的问题，常常是换了一种答法（没看到想看的，却明白了别的）。最后一句回扣开头的原话
- **一个反复出现的母题**：同一个意象或对照在不同地点出现 5–7 次，把散的段落缝成一部片。比如“几百年前的他 / 现在的我们”：几百年前他在这里过夜，现在这里是宾馆；他站在山顶写下一句话，我们站在同一个位置对照；二十年前这里还只有一根绳子
- **人物的内心变化**：“以前我觉得……，现在我……”。从执念到释怀，从躲开人群到愿意融入，从怕到不怕。这是观众最容易代入的部分

## 旁白怎么写

旁白是**一段一段**写的，不是一句一句写的。字幕按行切得很短，但声音不停。v7 把“字幕一行 ≤15 字”误当成“一句旁白 ≤15 字”，结果每句之间都要等，听起来很散。

**一段旁白的样子**（拆解实测，一支 57 分钟的样本）：

| | 样本 | 薄荷岛 v7 |
|---|---|---|
| 一段多长 | 10–60 秒，中位约 18 秒、80–90 字，一口气说完 | 2–4 句、每句约 11 字，中间等字幕 |
| 语速 | 4.7 字/秒（含停顿） | 用户读 4.2 字/秒，但句间停 1–2.6 秒，整体只有 3 字/秒 |
| 句间停顿 | 0.4–0.6 秒，最长约 1 秒 | 1–2.6 秒 |
| 旁白占全片 | 13%（其余是现场对话） | 26% |

所以**不是旁白越多越好**：样本里旁白总量不多，但每次开口都是一整段有来有回的话。

我们的片子旁白占全片 20–25%，只做画面做不到的事（悬念、反转、看不出的事实、感受）；每段最多一个知识点，并接回"我们"。不讲创始人生平、年份这类百科，讲"进去那一刻的感觉 + 一个具体细节"（巴厘岛 v1 讲了 The Yoga Barn 的创始人，片主要的是这个地方和感受）。

**一段旁白里要走的几步**（选两三步，连成一段）：

1. **事实 → 原因 → 人 → 我**：先讲画面里的东西是什么，再讲它为什么是这样，再落到人身上，最后回到我。例如：山体是整块光滑的花岗岩，本来不是人能走的地方 → 因为一个传说，山民和僧侣开始尝试 → 一代代人凿出台阶、搭起石桥 → 这座山才变得能爬，我们今天才能站在这里
2. **一句老话打开一种生活**：“八山一水一分田” → 空间很珍贵 → 所以有人家把房子往里让出一块给路人 → 这片地方的人情就在这里
3. **用当地历史解释我此刻的遭遇**（最好的一种）：古道上每隔几里有一座免费施茶的亭子 → 几百年后，爆了胎的我们，又被这些人的后代救了下来
4. **一个人的选择**：本地人在大城市工作十几年后回到村子 → 他为什么回来 → 他和这片土地、和全片主线的关系（“这趟追随古人的旅行，让我们认识了一个现代的侠客”）
5. **设问和转折**：“它真的像传说中那么美吗？”；“但我们的旅程还没有结束”；“计划是这样的。但是——车爆胎了”
6. **高潮用原话或诗句**：古人站在同一个位置写下的句子，或一句人人都会背的诗，放在最壮观的画面上

**句子的写法**：

- 句子可以长，用逗号连成一口气。字幕由剪辑工具按行切，写稿时不用管字幕多长
- 写成说出来的话，带上连接词：然后、其实、可是、所以、没想到、后来我才明白。实测用户读稿时会自己补“然后”“其实”“可比想象中……”，说明短促的书面句读着别扭
- 一段只讲一件事，讲透再换下一件
- 稿子里照常写标点；字幕上不出现标点，逗号变成空格（"原始 荒凉 却惊人的美丽"），剪辑工具自动处理
- 意象和硬事实交替：一句画面感（"血落在了大地 / 长出了龙血树"），一句数字（"岛上的七八万人口信奉伊斯兰教"）
- 用"为了……必须……"交代代价和动机："为了在绝对黑暗中亲眼见证传说中的蓝火，攀登伊真火山必须在凌晨两点出发"
- 高潮可以换成别人的口吻："他们会平静地告诉你：我们的父辈在这里用健康换取生命"
- 结尾回到观众："也守护每一个远道而来的你"

### 文案要有画面、有感受，不能只交代路线（巴厘岛 v3，2026-10-24）

片主："你看你这句：'从乌布要翻过巴厘岛中部的山。' 这个文学素养怎么这么差呢？"这句只是在报路线，像导航播报，没有画面，也没有感受。

- **写身体和眼睛感到的变化，不写地理说明**：
  - v3："第二天，离开海边往山里开。去乌布要翻过巴厘岛中部的山，车窗外的空气，一下子就凉了下来。"
  - v4："第二天告别大海，往岛中间的山里开。从海平面一路爬到一千二百米上下，空气一口比一口凉，山头罩进了云里，山窝里卧着一汪湖：布拉坦湖。"
- **比喻从当地取材**：小木船两边伸出的竹架"像一只只歇在岸边的水黾"；精灵坠崖是"一只低头喝水的霸王龙"，下崖就是"顺着霸王龙的脊背往下爬"
- **不用格言收尾，用一个具体的场面**：
  - v3："可有些东西，在那里站了三百年，说没就没了。"
  - v4："我们在这些石像跟前转悠的时候，那棵老榕树就在不远处的院子里站着，跟过去三百年的每一个下午一样。"
- **每段写完自查五件事**（编辑审稿时挑出的毛病）：
  1. 画面对不上：这句话说的东西，这一刻屏幕上没有
  2. 事实说过头：没核实的说成确定的（"最""第一""成千上万"），数字要有出处
  3. 金句、格言：一段最多一句，全片两三句
  4. 开头抛出的问题，结尾没有回答
  5. AI 腔：排比三连、"不是……而是……"、"仿佛""见证""诉说"、成堆的空洞形容词。清单参考 Humanizer-zh（github.com/op7418/Humanizer-zh）
- **整片初稿写完，先过一遍编辑**：开一个"中文编辑"子代理，只给它三样东西：每段的画面、必须守住的事实、初稿（格式见 `projects/bali-2026/narration_v4_draft.md`）。让它逐段挑问题、给改稿。我再逐段对照事实决定采不采纳。它替用户下的判断（"一点不像个三十多岁的人"）删掉；跟下一句口播重复的话也删掉（旁白说"课上不让拍"，紧接着用户自己就说了"课上不让录像"）
- 没有找到专门写中文文学文案的 skill，Humanizer-zh 只当清单用，没有安装

## 画面语法

- **建立空间**：航拍、大全景，人在画面里很小，衬出风景的尺度
- **第一人称**：脚、手、递东西、开车门
- **自拍讲话**：超广角，边走边说
- **特写**：食物、钱、小物件
- **地图和资料画面**：只在介绍一个地方时用，而且要做得足够好（真实卫星纹理、带地形、3D），做不到就不放；不拿来串场，地图太重（平面色块地图被片主否了）
- **夜景、延时、蓝调时刻**：作为段落的句号

## 字幕

- 单行、短，句末不加标点
- 对话和旁白都上字幕；外语对话配中文翻译
- **同一时刻画面上只能有一行字幕**。上一句必须在下一句出现前消失；渲染器按时间把每句的结束点截到下一句开始之前，两句叠在一起的“下午 坐突突车去靶场”不能再出现
- **你在说话时不放旁白**。不只是你的口播镜头：旁白下面的画面里只要听得见人声（原声放一半音量的镜头、无音乐段落里被调大的环境声），旁白就不能压上去。剪辑工具会对照转写稿检查，压到了就报错
- 片名这类卡片出现的时候，画面上不能同时有字幕；卡片放在没人说话的镜头上

### 样式规格

从样本原片（720p）逐像素量出来，按画面高度 H 换算。4K 成片就乘 2。

| 项目 | 规格 | 720p | 1080p |
|---|---|---|---|
| 字体 | 资源圆体 Light（剪映里叫"资源圆体 细"），文件 `fonts/ResourceHanRoundedCN-Light.ttf` | | |
| 字号 | 0.036 H（用户要求比 0.039 H 再小一点） | 26 px | 39 px |
| 字距 | 约 0.2 em | 5.2 px | 7.8 px |
| 文字 | 纯白，无描边，无阴影 | | |
| 底框 | 黑色 60% 不透明（用户两次要求更透；压在亮画面上呈深灰，不能是死黑），紧贴文字，宽度随字数变化 | | |
| 底框内边距 | 左右 0.012 H，上下 0.0065 H | 9 / 5 px | 13 / 7 px |
| 底框高度 | 0.044 H | 32 px | 48 px |
| 圆角 | 0.005 H | 4 px | 5.5 px |
| 位置 | 水平居中；底框下沿距画面底边 0.047 H | 34 px | 51 px |

实测原片底框不透明度 75–83%；用户要求明显的半透明，先定 70%，第三版后又要求再透一点，现为 60%。

注：常见的"半透明灰底 + 白字"效果也可能来自播放器的 CC 字幕（YouTube 默认 `rgba(8,8,8,0.75)` 白字），那种字幕并不在画面里。这里的规格是烧录进画面的。

## 旁白（用户自己配音）

- 旁白稿 = 用户要录的话。剪辑时它以字幕形式出现，**出现时背景音乐自动压低**，给配音留位置（压多少见"音乐有三种状态"和"混音"）
- 旁白从用户给的行程简介扩写到整片：不只是把用户给的内容换个说法，要主动查当地的地理、历史、文化、人的生活，找出能和用户经历接上的那一点（见上面“一段旁白里要走的几步”）
- 按段写（`b.vo('一整段，带标点。', broll=...)`），剪辑工具自动切成字幕行，按用户实测语速排：4.5 字/秒，句号后停 0.45 秒，分号 0.3 秒，逗号 0.15 秒；英文单词按 2 个字、数字按位数算。空镜长度跟着旁白走
- 旁白稿按段导出（`narration_script.py`），每段标“一口气读完，约 N 秒”。告诉用户：一段一个录音，看着稿子读，不要跟着画面上的字幕读
- 讲知识只讲查证过的事实（如 OW 最深 18 米、AOW 30 米；眼镜猴拳头大、眼睛按身体比例是哺乳动物最大）；有争议的说法（日期、地点、数字各家不同）要么不讲，要么用“据说”；用户自己口播里说的数字照原话上字幕，不改
- 感受类的句子（“那一分钟比想象中长”“我已经很久没这么安静过”）是替用户说话，交稿时标出来，让用户按真实感受改；不替用户编没发生的经历

## 口播

- 用户的口播尽量用上，它比旁白更真实。用 `scripts/clean_speech.py` 去掉"嗯啊"、长停顿、说一半重来；同一句重复说了几遍，只留最后一遍
- 字幕用改正后的文字（地名、错字），按逐字时间戳对齐
- 有趣的对话片刻要整段保留节奏（比如教练说"30"米，你连问三遍"70？"），不要为了精简剪掉笑点
- **好笑的口播是主角**：用户录了一大段的场景（出海钓鱼）就用原声讲完整个故事，笑点后留 0.5–1 秒再切，切同伴的反应；少量花字（`kind='pop'`，每个笑点最多一条，放在笑点之后）；这一段音乐停掉或压很低，不用旁白科普。缩短片长时先删旁白和空镜，不删原声
- **口播的入点和出点**：开口前至少留 0.25 秒，说完至少留 0.7 秒，停顿不到 1.2 秒的连着放、不切碎。剪辑工具按音频找说话的边；第一个字被相机开头的静音吞掉、字幕上的字在声音里听不到、切点落在半句话上，都会报错（细节见 `toolchain.md`）。片子太长时整段对话一起删，不留半句

## 素材筛选

- **精华优先**：长的水下镜头先看每 4 秒一帧的缩略图，找出鱼群、海龟、特别的瞬间，再结合稳定度选具体几秒
- **找素材要看全**：转写稿里每段有内容的口播都要过一遍（巴厘岛 v1 漏了"人生第一次跑 10 公里"）
- **来源不明的素材先问**：文件名、分辨率、竖屏和用户相机都对不上的（像朋友或船家发的），用户口述里也没提到的，先确认再用，不在旁白里替它编经历

## 镜头必须稳

- **空镜、水下镜头、航拍都不能晃、不能歪**。水下最常见的问题是镜头左右翻滚（歪歪扭扭），平移抖动的检测量不出来，要单独测旋转
- `scripts/motion.py` 逐秒测三样：抖动（像素）、翻滚（度/秒）、移动方向。阈值是用这次的反馈定的：你表扬的小鱼群镜头（c154，14:10）抖动 1.0、翻滚 2.8°/秒；你说歪歪扭扭的那几个（13:07–13:30）翻滚 8–41°/秒
- 空镜限值：平均抖动 ≤ 2.5，最大 ≤ 4.5；平均翻滚 ≤ 4.5°/秒，最大 ≤ 9°/秒。口播镜头天生手持，放宽到平均抖动 ≤ 5、平均翻滚 ≤ 8
- 不达标的镜头，剪辑工具直接报错，并列出同一段素材里稳定的时间段；一个都没有就换素材或者不用。宁可少一个镜头，也不要放晃的
- 鱼群、气泡占满画面时，算法会把游动的鱼当成镜头在动。这种只能看画面判断：抽 2 帧/秒的缩略图，背景珊瑚不动就算稳，在剪辑脚本里写明理由（`allow_motion`）
- 好镜头的样子（用户表扬过）：Momo 的小鱼群，镜头几乎不动，鱼群从画面里游过，颜色鲜艳，一个镜头 5–6 秒

## 稳还不够：要正，要有东西

- **画面要正**：人或地平线明显歪着（身体斜成对角线、整个画面倾斜）的镜头不用。运动检测只能测出镜头在不在转，测不出镜头一直斜着。所以每个水下镜头都要抽 1 帧/秒的缩略图看一眼
- **画面里要有东西**：要有人、有鱼、有珊瑚。空荡荡的蓝水、一团气泡、只有纹理的光秃崖壁，都不算好镜头（第五版 13:00 前后就是这种，用户说“没有一点营养”）
- **从当天全部素材里挑，不要从剪辑表里已有的那几段里凑**：`scripts/candidates.py` 把当天所有素材里通过运动检查的段落按颜色和细节打分，做成缩略图板，逐个看过再选。分数只用来排序，最终要看画面：光秃崖壁的分数也很高
- **别人拍你的镜头最值钱**：潜导、潜伴拍的你（c146 是潜导拍的），比自拍和空镜好看得多，优先用
- **用户点名的镜头一定用上**（c143 1:26 的鱼群、c150 1:56 的小黄鱼），只截掉明显晃或翻转的部分
- 好的水下段落（第七版最后一潜）：每个镜头 4–6 秒，人、鱼、珊瑚交替出现，按下水的顺序排
- **用户在剪映里自己改的（第七版之后）**：Napaling 那 20 秒，杰克鱼群和崖壁空镜全换成了人贴着崖壁下潜的镜头（c140、c152、c141 122 秒、c150 100 秒）；Momo 结尾删了两个“很透的蓝水 + 气泡”（c156），换成自己戴面镜的特写（c155、c154 多留 4 秒）。结论：
  - 同一段里，**有人的镜头优先于只有鱼的镜头**。鱼群要么有人在前景（c143 沙丁鱼、c154），要么就少用
  - 蓝水再透也是空的。“画面里要有东西”这条第七版自己又违反了一次
  - 同一天的潜水，画面好比严格的时间顺序重要：用户把下午 Momo 的 c152 放进了上午 Napaling。重剪时照用户的排法，`back=True` 并写明“用户在剪映里这样排”
  - 旁白跟着画面走：杰克鱼删了，“它们从峡谷里游了出来”这句也要删

## 航拍：只给大场景（2026-10-25，片主："无人机镜头也别滥用，只有在大场景的情况下才用"）

"大场景"是站在地上拍不出它的样子、或拍不出它有多大的地方。航拍只用在这四种时候，剪辑脚本里每个航拍镜头都要写明是哪一种（`aerial=`），没写就报错：

1. **新地方的第一眼**（`first`）：只限换岛、换城市、换天这一级，交代它长什么样、在哪儿、有多大。一个地方一次
2. **形状只有从天上才看得出**（`shape`）：霸王龙崖、破碎海滩的石拱、梯田、火山口
3. **一段的收尾**（`end`）：故事讲完，拉到大景收住
4. **片头、片尾的片名**（`title`）

- 不用在街道、吃饭、室内、对话段，也不拿航拍去填满一段旁白
- 一个地方最多两个航拍镜头（第一眼加收尾，片名不算），不连着放三个。剪辑工具按时间地点戳分地方来数，超了就报错。巴厘岛 v4 的破碎海滩连放了 4 个，按这条要砍到 2 个
- 第一眼的航拍先不配旁白，见"不配音的镜头"
- 用户这趟没带无人机、又需要第一眼或形状镜头时，用图库航拍补，怎么找、怎么调色见 `footage-sources.md` → 用户素材里没有的航拍

**航拍只用一个方向的运动**：

- 高质量的航拍是一条连续的运动：一直往前飞、一直拉升、一直平移或一直环绕。中途停下、折返、先推后拉的段落不用
- `motion.py` 对航拍检查左右、上下、远近三个方向，任何一个方向在镜头里变号（先左后右、先推后拉）就算折返，剪辑工具报错
- 选航拍时先看整段，挑出动作最完整的 4–6 秒，起点和终点都在动作中间，不要剪到无人机刚起步或刹车的地方

## 旁白说什么，画面就要有什么

- 旁白提到一个具体的东西（沙丁鱼风暴、杰克鱼、海龟），画面里必须同时看得到。先在素材里找到它，再写这句旁白
- 找不到就问用户在哪段素材里，或者改掉这句旁白；不要拿别的鱼群、别的画面凑
- **用户点名的关键画面，先截一帧给用户确认，再整片渲染**。第三版我把气泡和小鱼（c143 104–114 秒）当成了沙丁鱼风暴，用户要的是同一段素材开头、自己在前景、身后一大群银色鱼游过的那几秒（7.4–12.4 秒）。用户给了截图或文件名，就以那一帧为准
- 用户亲自选的镜头，即使手持有点晃，也照用（`allow_motion` 写明“用户指定”），只截掉明显翻转的部分
- 一句旁白和画面对不上（比如 4:30 日落时说“明天的 30 米”），就删掉，让画面和音乐自己走
- **主角要选拍得最多、最清楚的那几秒**（巴厘岛 v3，片主："追海豚那个地方，你选的照片里也没几条海豚……怎么不选那个海豚多的呀？"）：把这一段的视频和照片都按 1 fps 扫一遍，数每一帧里有几条海豚，选同框最多的那几秒（c037 里五六条一起出水的那一群），最多的那一帧截出来做成定格照片（`ffmpeg -ss` 截帧后加进 `photos.json`）
- **一段里不混进无关画面**：讲海豚的时候插进了一张大蜗牛照片（同一个早上拍的，按时间凑进来了），片主问"和追海豚有什么关系吗？"。每一个 B-roll 都要跟这段旁白讲的事有关。按时间顺序往里补照片时最容易犯这个错
- **旁白提到一个看得见的东西，素材里没有，就找图放出来**（片主："这里说的是 5 万块钱的背景，是不是可以把那个印尼 5 万块钱的钞票给放出来看看？"）：去 Wikimedia Commons 之类找公有领域、可自由使用的图，做成剪报样式浮在同一地点的画面上，用荧光笔扫过要看的部分（`news={'bg': [clip, t], 'hl': [x0, y0, x1, y1], 'w': .., 'h': ..}`：荧光笔框是卡片上的左上、右下两个角，按卡片宽高的比例；`w` / `h` 是卡片占画面的比例），出处和授权记进项目的 `news/SOURCES.md`

## 名字不要自己编

- 地名、路线名、段落标题用当地或游客普遍使用的叫法，先查再写。例：巧克力山、眼镜猴、洛博克河这条线，官方叫 Countryside Tour，中文攻略多叫“陆地一日游”，不是“传统路线”
- 拿不准的名字（鱼的种类、景点的叫法），写之前先查资料；查不到就用描述代替名字

## 不重复、按时间顺序

- **同一段画面只用一次**。内容相同但文件名不同的素材（朋友传的副本、导出的重复文件）算同一段；`scripts/dedupe.py` 会找出来
- **开场预告用过的素材，正片里不再出现**；预告只挑正片不用的镜头
- **正片按拍摄时间推进**。没有拍摄时间的素材：自己 iPhone 的 IMG 视频用文件修改时间（和照片编号对得上）；朋友传的副本，文件时间是传输时间，要手动标注
- 用户口述的经历顺序和拍摄时间对不上时，以拍摄时间为准，在交付时说明
- 某一天没有画面（比如深潜那天一个镜头都没拍），不要借别的日子的画面冒充，可以在后面的段落用旁白回忆

## 照片

- **不用裸上身的照片**，也不用其他可能让人不想公开的照片（衣衫不整、表情难看、别人的私人时刻）。同一组里挑穿着得体的那几张；没有就不用这一组

- 视频素材不够的地方（比如眼镜猴、萤火虫）用照片补。照片同样按拍摄时间（EXIF）排进时间线
- 做法：快门声 + 0.2 秒白闪，**原图按画面高度放在黑底上**（竖拍照片两边留黑，完整显示不裁切），镜头缓慢推近约 4.5%。不加模糊背景、白边和阴影：第七版用的是“白边 + 同图模糊压暗当背景”，用户在剪映里把所有照片都换回了原图，并确认就要原图
- 一组照片 2–4 张，每张 1.3–2.5 秒；带现场音乐的表演段不要插照片（照片会切断现场声）
- 夜里拍的照片（萤火虫、星空）几乎是黑的：渲染时自动提亮；就算这样，内容相近的暗照片最多放 2–3 张，不要连放 20 秒黑画面
- **新闻事件做成剪报**：截图重排成报纸卡片，浮在自己拍的同一地点的画面上（虚化压暗），卡片升起、整体慢推、荧光笔扫过标题（`photo` + `news={'bg': [clip, t], 'hl': [...]}`）；先用自己的画面埋一句，再进新闻；音乐换成很低的铺底（巴厘岛 v1 把网页截图直接放在黑底上，片主说生硬）

## 画面文字（片名、时间地点戳、一句话卡片）

- **小而轻**：预告句约 0.043 H（1080p 下 46 px），字距宽，白字只加一层很淡的柔和阴影；**不加黑色渐变底**，大字和渐变底都显得笨
- **简洁的一句话一律放画面正中**。不要为了避开画面内容把它挪到角落、上方，位置刁钻反而难看
- **片名照片主的薄荷岛**：小号居中，做旧粗体（英文 Lilita One，中文思源宋体 Black，加做旧纹理），英文在上中文在下，逐字出现、逐字散去（`kind='title', style='stamp'`）。开头落在航拍大景上，结尾再出现一次。巴厘岛 v1 用的大号笔刷英文 + 马克笔中文、整块淡入，片主说"傻乎乎的"
- **时间地点戳照片主的泗水那期**："罗威纳 | 06:10"，左下角细字，地点先出、时间晚一拍（`b.place('罗威纳', '06:10')`），在新地方的第一个大景上出现。时间一律用当地时间，相机时钟不对要先校正
- **时间地点戳、花字放在画面干净处**（天空、水面），不压在人脸、船身、招牌上；先截一帧看位置再定 `y`，渲染后逐张检查
- **字体只用年轻的**：不用毛笔书法、楷体、正式花体，片主说看着老气。字体都在 `fonts/`，全部是开源许可，目录和用途见 `fonts/README.md`

## 素材不够惊艳时，怎么让片子丰富

不是每个镜头都是大片。下面这些手法能让普通素材也有层次：

1. **细节镜头穿插**：路牌、餐盘、钱、门牌、小动物、手上的动作、水面反光。每段对镜头讲话之间插 2–4 个 1–2 秒的细节，把信息和氛围补上
2. **转场手法**（漏光已经做进渲染器；前景遮挡靠素材里有东西划过；甩镜、画幅变化还没做，要用先改渲染器）：
   - **漏光闪白**：一闪暖色的光盖过切点，适合换场景、换日子
   - **前景遮挡**：镜头从树叶、柱子、人前面划过，划过去就切到下一个场景（素材里找有前景划过的镜头）
   - **甩镜/动态模糊**：两个镜头在快速横移的拖影里接上
   - **画幅变化**：突然切成竖幅或 4:3、两边留黑，像一张照片，再恢复全屏
3. **文字动效**（还没做）：一个关键词铺满画面（大字、可以镜像或分层），给段落一个视觉重音
4. **对话场景也能好看**：船上、餐桌上的聊天，用"说话人 + 听的人的反应 + 环境细节"三种镜头交替，不要一个机位从头放到尾

## 调色

- **同一段素材只能有一套调色**。不能一个镜头按水下校正、下一个镜头按普通画面，同一只海龟在两个镜头之间颜色跳变。渲染器按素材（而不是按镜头）测一次参数，用在这段素材的所有镜头上

全片统一一个"电影感"色调（`scripts/grade.py` 的 `film` 这一档），水下镜头先单独校正再套色调。

**水下校正**（每段素材测一次参数，用在这段素材的所有镜头上，不闪烁）：
1. 补红：水先吸收红光；按"绿比红多多少"把一部分绿加回红（力度适中，运动相机噪点多）
2. 白平衡：往"保留一点蓝绿的热带海水"拉，**不要拉到中性灰**，否则深蓝的水会变成紫色
3. 拉对比：主要按亮度拉，少量按单个颜色拉（全按颜色拉会偏色），相当于轻度去雾
4. 轻降噪 + 轻锐化 + 饱和度略提
- 自动识别水下镜头（红色明显低于绿、蓝），也可以在 EDL 里给镜头写 `"grade": "underwater"` 或 `"none"`

**电影感色调**：柔和的 S 形曲线，暗部略偏青、亮部略偏暖，饱和度略提；**暗角要很轻**（四角压暗一点点，不能看出黑边）；极少量动态颗粒。

**改了调色参数要出前后对比图**：`python3 scripts/grade.py out.jpg <clip>:<秒> ...`，水下镜头至少挑浅水、深蓝水、有人脸、有珊瑚四种各一张。

## 转场

- **叠化只用在时空跳跃上**（换天、换岛、换城市；同一片区域里换地方用过桥段、不叠化，见"场景之间怎么接"），每分钟不超过 1–2 次。同一个场景里用硬切，靠**声音过桥**：下一场的环境声或第一句话提前 0.5–1.5 秒进来（`jcut=0.8`），一句情绪话之后让声音拖尾压到下一个空镜上（`lcut=1.0`）。巴厘岛 v1 每换一段素材都叠化 0.35 秒，画面软了，但声音和画面在同一帧一起换，片主的妈妈还是觉得"突然切掉、进入一个镜头"
- 说话镜头接在叠化后面时，声音的淡入只用 0.12 秒，不然第一个字会被吞掉（渲染器已处理）
- **漏光**：一团暖色（红、橙、琥珀，不能有绿和粉）从画面一侧边缘渗进来，盖在剪辑点上，0.8–1 秒；画面中间基本不受影响。整屏一片色雾显得廉价
- 一分钟里用 1–2 次，放在段落切换处（进片名、出发、换日子），不要每刀都用

## 音乐和声音

音乐是片子的灵魂。它要说出**这个地方**和**这一刻的心情**，不是一层从头铺到尾的底。

**谁找歌**（2026-10-25 定）：片主自己找（剪映 SVIP 曲库等），我写配乐表，告诉他每一段要什么、在哪进、在哪出；片主在成片下、带着人声、用真实音量试听后定。有没有代入感只有人耳听得出来，我只能测量。授权按发布平台核对：剪映的商用音乐只有标"全渠道"的能发小红书。片主让我找时，我才从免费曲库找（见"自己找歌时"和 `music-sources.md`）。

### 配乐表：先定作用，再定类型（2026-10-25）

巴厘岛 v4 的配乐被片主说"完全没有代入感"：全片 11 首风格各异的歌（乡村、流行、儿歌风、lo-fi）换了 15 次，观众每两分钟就被拽进一种新情绪。参考做法（出处见本节末）：

**全片先定一套声音**：两三样核心乐器、一个速度范围、一句话说全片情绪怎么走。各段在这套声音里变疏密、变明暗，不换风格。15–20 分钟的片子分 4–6 段配乐，一段对应一个故事段落，不是一个地点。

**每段一行**，停音乐的地方也写一行（类型写"无"并写原因）：

| 段落、时间 | 作用 | 情绪 起→转→落 | 曲风 | 乐器 | 速度 | 乐器数量 | 一对反义词 | 入点 / 增长 / 落点 / 退出 | 不要 |
|---|---|---|---|---|---|---|---|---|---|
| 出海钓鱼 5:10–7:20 | 期待落空的自嘲（不是"搞笑"） | 兴冲冲出发 → 晕船、没鱼 → 认命 | 原声 | 拨弦吉他、尤克里里 | 约 90 BPM | 少，两三样 | 俏皮，但不滑稽 | 开船的大景进；说话时压低；船长收线那句前退出，留白 | 儿歌感、鼓点、音效 |

- **作用先于风格**：先写这段音乐要做什么，再挑类型。画面已经说了的情绪不用再配一遍，按潜台词配：出糗的场面配的是"自嘲"，不是滑稽
- **类型按这个顺序定**（Austen Menges 的五步选歌法）：先把目标情绪写下来 → 曲风 → 这个曲风里用哪几样乐器 → 速度（慢约 60、中约 100、快 120 以上，跟剪辑节奏走）→ 乐器数量（少显得收着、私密，多显得盛大、有能量）
- **用一对反义词描述**："温暖，但不煽情""轻快，但不幼稚"，挑歌时不容易偏
- **入点、增长、落点、退出都写出来**：从哪个镜头进、在哪里加厚、最强的一拍落在哪个镜头、怎么退（淡出、硬切、留白）。退出放在故事转折上，不是每次换镜头都动
- **片主喜欢一首有版权的歌时，把它翻译成属性**：速度、乐器、疏密、明暗，拿这些去有授权的曲库里找，不用原曲

**按场景选类型的起点**（再按这一段的目标情绪调）：

| 场景 | 配什么 |
|---|---|
| 开场、片名 | 全片的主题曲，中速 95–110 BPM，最强的一拍落在片名上；结尾这首再回来 |
| 赶路、到达、航拍第一眼 | 开阔、长音铺底、分解和弦，约 70–90 BPM，往大景里推；或者整个停掉，让第一眼不配音 |
| 口播、聊天 | 稀疏的原声吉他或钢琴，约 70–80 BPM，没有主旋律、没有人声；lo-fi 的鼓要很轻 |
| 搞笑、出糗 | 轻、干、拨弦，按潜台词配；笑点那一下留白，不加音效 |
| 寺庙、宁静的地方 | 不放音乐，或者只有很淡的铺底，让现场声说话 |
| 情绪转折（坏消息、新闻） | 先把音乐撤掉，再进稀疏的钢琴 |
| 夜店、现场演出 | 用现场自己的音乐，不另配 |
| 晨跑、运动 | 唯一适合用鼓、往前推的地方，110–125 BPM，剪辑点可以卡拍 |
| 结尾 | 开场的主题回来，慢一点、暖一点，放到它自己的结尾 |

出处：Austen Menges《PRO Editor Reveals How to Pick Perfect Music for ANY Video》（YouTube XEhoNEAYyKM）；github.com/calesthio/generative-media-skills（music-supervision-scoring）；github.com/appariciojunior/video-editor-skills（music-and-sound）；github.com/JimLiu/baocut（catalog/music.md）；github.com/Yunwuxin-666/Wuxin-Film-Skill（音乐.skill）

### 什么时候必须把背景音乐全部停掉

下面这些时刻，**现场的声音就是内容**，背景音乐必须完全退出（不是压低），并且把这段留得足够长：

| 场景 | 例子（薄荷岛） | 留多长 |
|---|---|---|
| 有人唱歌、现场演奏 | 晚饭时两个孩子弹尤克里里唱歌；洛博克河船上的乐队 | 唱到一个完整的段落，常常 15–45 秒；最打动人的那段整首放 |
| 带伴奏的表演、舞蹈 | 竹竿舞的现场伴奏 | 跳完一个回合，10–20 秒 |
| 声音本身是看点的自然场景 | 瀑布的水声、海浪、夜里只有船桨声的河 | 5–15 秒 |
| 安静就是氛围的地方 | 教堂里、寺庙里、清晨 | 进去的那几个镜头 |
| 本人的呼吸、心跳、喘气 | 水下的呼吸声（"现在我可以在这里慢慢呼吸"） | 那一两句话 |
| 现场的笑点、真情流露 | 惊叹、大笑、一句很重的话 | 说完再留 1 秒 |

做法：前一首歌在乐句末尾 1.5 秒淡出（`b.music_out('原因')`），现场声音按原音量放（`audio='live'`），表演结束、换到新场景时，下一首歌在一个大镜头上进来。在剪辑表里写清楚为什么停，自检时逐条核对。

### 自己找歌时：地域感和测量

- **用乐器和曲风带出地域，但不要把一个国家简化成一种乐器**。东南亚海岛：尤克里里、原声吉他、轻柔的原声流行；不要通用的企业宣传片式流行乐
- **海岛片不要用鼓点很重的电子乐**。热带浩室（tropical house）听名字像海岛，其实是电子舞曲：鼓点和低音一直在推，配浮潜、海龟、口播会显得很跳脱、很吵（第二版 5:20 的 Mirihi 就是这样）。电子鼓只适合开场 20 秒的快剪
- **潜水、水下也要轻快明亮，不能沉重**。没有鼓还不够：John Bartmann 的 *Underwater Wonders* 低频占比 55–77%、频谱重心只有 300–470 Hz，用户听来“贼沉重”。水下用明亮的原声吉他、尤克里里
- **冲不冲、沉不沉重都靠测量**（我听不到声音），`scripts/music_check.py` 一次测完，每条限值都来自一首被片主否掉的歌：鼓点（打击乐）能量占比 > 11% 而且低频 > 20%，算有整套鼓（Mirihi 28% / 72%；尤克里里扫弦也有打击感，但没有低频，Monplaisir《Hop》17% / 0% 没问题）；低频（约 130 Hz 以下）≤ 35%；频谱重心 ≥ 1000 Hz；再加下面的失真检查。小调只提示，不否决
- **还要测失真（摇滚、重金属）**：失真电吉他是“谐波”，鼓点检测抓不到，而且高频多、频谱重心高，会被误判成“明亮”。第五版 13:22 的 Monplaisir《On est bien, là》就是这样漏过去的，用户说“暴躁”“重金属摇滚”。三个指标：
  - 密度（响度第 10 百分位 / 第 90 百分位）≥ 0.75：一堵声墙，没有呼吸
  - 4 kHz 以上能量占比 ≥ 3%：失真的毛刺
  - 动态范围（峰值 / 平均）≤ 12 dB：压得很扁
  - 前两项同时超标就不用。对照：用户认可的尤克里里密度 0.03–0.27、高频 0–0.4%、动态 19–22 dB
- **同一个作者、同一张专辑不代表同一种风格**：Monplaisir 的 *Relaxing Ukulele* 很安静，*GOOD* 里却有摇滚。每首都要单独测
- **最能代表地方的，是你自己录下的当地声音**：孩子唱歌、船上乐队、竹竿舞伴奏，优先用这些现场音，而不是找一首"像菲律宾"的配乐
- **音乐表达旅行者的心情，地方感来自画面、人声和环境声**
- **免费曲库按地域找**：Mixkit 曲库小、偏通用，没有热带、尤克里里这类分类；Free Music Archive 可以按关键词搜，用 `scripts/fma_search.py` 只留 CC0 和 CC BY 的歌，授权逐首从歌曲页读取

### 音乐有三种状态，按段落切换

音乐不是一条从头到尾的底。它跟着段落在三种状态之间切换，**节奏感来自这种交替**，每隔 30 秒到 2 分钟换一次：

| 状态 | 音量（相对最强处） | 用在哪里 |
|---|---|---|
| **满** | 0 dB；有旁白时压低 13 dB | 开场、片名、风景混剪、诗意旁白、讲知识的旁白。旁白是"长在音乐上的"，音乐不让路 |
| **低** | 低 12–18 dB，似有似无 | 现场对镜头讲话、交代信息的对话。音乐只起粘合作用 |
| **无** | 完全退出，只留环境声 | 现场对话的笑点和真情流露、爬山喘气、夜里、一句很重的话。让真实的声音说话 |

- **切换的手法**：进入"无"或"低"时，音乐在一个乐句末尾用 1–2 秒淡出，不要在小节中间硬切；回到"满"时，音乐在强拍上进来，同时切到一个建立空间的大镜头。这一刀就是全段最该卡点的地方
- **"无"的长度**：一般 4–30 秒；现场唱歌、演奏放完一段可以到 45 秒（见上表）；其他超过 40 秒要有理由（夜晚、沉重的时刻），一支片不超过一两处
- **往空镜里推**：口播说完、进空镜时，音乐提前约 1 秒开始升，1 秒左右升满，让空镜顺着音乐出来；下一句开口前降回去（`jcut`、`lcut` 管的是现场声，这条管音乐）
- **情绪转折前先撤**：在最重的那一刻之前把音乐撤掉，不要等到那一刻才撤；撤掉以后是现场声，不是死寂
- **不要逐句压缩**：不要让音乐每句话都忽大忽小，那样听起来像在喘气。一场对话里音乐要么一直低，要么一直没有
- **反例**：音乐一直铺着，说话时只压低 3 dB。现场对话和音乐会抢，听着累，也失去了"安静下来"的力量

### 换歌

- **换歌 = 换段落，歌和歌之间要断开**：前一首在段落结束前淡出，留 1–3 秒自然声，新段落的第一个大镜头再进新歌。不要无缝从一首接到下一首
- 一段配乐撑一个故事段落（3–5 分钟），中间有"低"和"无"的停顿。一首歌不够长，就在停顿之后让它从合适的乐句重新进来，或换成同一套声音里的另一首；不要循环同一段
  - 开场一首，片名后换掉，结尾再回来
  - 转折旁白（"但在行程开始前，另一件事儿把我们难倒"）时换歌，提示观众进入新的段落
  - 每段配什么类型，见上面的配乐表和场景表

### 卡点只用在局部

- 长视频的剪辑点**不需要每刀卡拍**。节奏跟着说话和动作走；样本里的剪辑点落在拍点上的比例和随机差不多
- 卡点只用在这几处：开场、片名出现、换段落的第一刀、纯音乐的风景混剪段
- 换歌时新歌的第一个强拍要对上新段落的第一个镜头

### 混音

- 音乐音量按上面的三种状态来；现场原声优先，旁白必须清楚
- **说话时，音乐比人声至少低 18 dB**。按每个口播镜头实际测到的人声音量来压，而不是统一压 13 dB：人声小、歌又响的地方（第二版 5:20）固定压法会盖住人声。自检要求每个口播镜头的人声比音乐高 15 dB 以上
- **每首歌先统一到同一响度再用**。不同作者的母带响度能差 6 dB 以上，热带浩室比尤克里里响得多，不统一就会一段吵一段轻
- **不能有死寂**。停掉音乐的地方，画面本身必须有声音：环境声在没有音乐时自动提到一半音量；照片、航拍这类没有声音的镜头，要么配音乐，要么垫一段现场声（瀑布照片垫瀑布声，萤火虫照片垫夜里河上的声音，`bed=`）。自检会找出任何 1.5 秒以上的静音
- 样本数据（供对照）：一支高质量样本说话时音乐中位数比最强处低 14.5 dB，62% 的说话时间音乐低于 -12 dB；另一支只低 7.8 dB，现场对话和音乐互相抢
- 整体响度 -14 LUFS，峰值不超过 -1 dBTP
